Folia Companion

Connects this Chrome profile to the Folia desktop app so Folia can control the Apple Music web player at music.apple.com.

Not configured.

Paste either the number (32110) or the whole address Folia shows (ws://127.0.0.1:32110) — both work.

Prerequisites

  • Folia is running with external media control enabled (that is what opens the port).
  • A music.apple.com tab is open in this Chrome profile.
  • You are signed in to Apple Music there, with an active subscription.
  • The page storefront matches your account storefront (for example, a /cn/ page with a cn account). A mismatch silently forces the web player into preview-only mode.

What this extension does and does not do

It calls the music.apple.com page's own MusicKit playback methods and reads the page's own player state. It does not touch DRM: no key-system access, no license data, no decryption, no stream capture or proxying. Playback only works when the page itself can play it.
